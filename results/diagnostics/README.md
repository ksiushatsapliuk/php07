# Пробний запуск, відхилений для підсумкової таблиці
22.10.2026 у першій спробі серія N+1 з індексом мала 200 завершених запитів, 1 Failed request (Length) і 1 відповідь Non-2xx. Засіб вимірювання завершився з помилкою та не створив підсумковий summary.json для цієї спроби. Точний HTTP-код і причина цієї окремої відповіді в її AB-звіті не збережені, тому причинний висновок не робиться.

Після ввімкнення журналу PHP та однакового max_execution_time=300 для всіх тестових копій виконано нову повну серію з новою тестовою БД. Сім підсумкових AB-звітів у батьківській папці мають 200 завершених запитів кожен, Failed requests=0 та не містять Non-2xx responses. Цей пробний файл залишено лише як діагностику; його метрики не змішуються з результатами повторного запуску.
